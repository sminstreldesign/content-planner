# Контент-план — первая версия

Файлы сайта готовы для GitHub Pages. Это обычный HTML/CSS/JavaScript без установки программ и `npm`.

## Что уже есть

- регистрация и вход по email;
- список своих проектов;
- создание проектов с названием и описанием;
- отдельный путь для уже созданного проекта: соцсети или сразу контент-план;
- рубрики, соцсети и публикации;
- уникальный восьмизначный код для приглашения;
- роли: читатель, комментатор, редактор, владелец;
- палитра Powder / Peanut / Stone / Pecan.

## Перед первым запуском

1. Откройте Firebase → Firestore → вкладка «Правила».
2. Замените содержимое правилами из `firestore.rules` и нажмите «Опубликовать».
3. Добавьте эти четыре файла в корень репозитория GitHub: `index.html`, `styles.css`, `app.js`, `firestore.rules`.
4. В GitHub откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`, затем сохраните.
5. На Firebase → Authentication → Settings → Authorized domains добавьте адрес сайта GitHub Pages после его появления.

## Важное ограничение первой версии

Код приглашения состоит из восьми цифр. Владелец может выбрать одну роль для текущего кода. Позже можно добавить несколько отдельных кодов, срок действия и персональные приглашения по email.
